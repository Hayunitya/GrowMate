# 🌱 GrowMate

GrowMate adalah aplikasi mobile yang membantu pengguna dalam merawat tanaman mereka dengan mudah dan efisien. Aplikasi ini dirancang untuk memantau kondisi tanaman, memberikan notifikasi perawatan, serta menawarkan tips bercocok tanam yang sesuai dengan kebutuhan.

---

## 🚀 Fitur Utama
- 📋 **Manajemen Tanaman** – Tambahkan dan kelola daftar tanaman yang kamu miliki.  
- ⏰ **Pengingat Perawatan** – Dapatkan notifikasi otomatis untuk menyiram, memberi pupuk, atau mengganti media tanam.  
- 🌤️ **Integrasi Cuaca** – Pantau kondisi cuaca lokal untuk menyesuaikan perawatan.  
- 📚 **Tips & Artikel** – Dapatkan rekomendasi cara perawatan sesuai jenis tanaman.  
- 🔔 **Notifikasi Real-time** – Ingatkan aktivitas penting terkait tanaman.  

---

## 🛠️ Tech Stack
- **Framework**: Kotlin
- **Backend**: Firebase  
- **Database**: Firebase Firestore
- **State Management**: ViewModel dan LiveData
